可怜BOT现在支持自由组合以下的条件来查询b50/b40、分数列表以及完成表/定数表，目前支持的条件如下：

### 乐曲范围限定

| 条件                                                                                    | 示例                                    |
|---------------------------------------------------------------------------------------|---------------------------------------|
| **分类**<br>  舞萌<br>  vocaloid/v家/术力口/ボカロ<br>  东方/车万<br>  流行动漫/二次元<br>  音击/中二<br>  其他游戏 | `@可怜BOT` **东方**50                     |
| **版本**<br>真/超/檄/橙/晓/桃/樱/紫/堇/白/雪/辉/舞/熊/华/爽/煌/宙/星/祭/祝/双/宴(+代)                           | `@可怜BOT` **辉**50<br>`@可怜BOT` **白代**50 |
| **谱师**<br>mai-Star/哈皮/谱面-100号/Jack/翠楼屋/...                                            | `@可怜BOT` **maistar**50                |
| **难度**<br>绿/黄/红/紫/白                                                                   | `@可怜BOT` **红谱**50                     |
| **等级**<br>15/14+/14/13+/13/12+/12/...                                                 | `@可怜BOT` **13**分数列表                   |
| **定数**<br>14.5/13.9/12.5/...                                                          | `@可怜BOT` **14.3**分数列表                 |
| **类型**<br>旧框/dx                                                                       | `@可怜BOT` **dx**50                     |
| **时间**<br>旧版本/新歌                                                                      | `@可怜BOT` **新歌**50                     |
